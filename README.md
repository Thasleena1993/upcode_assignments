# Python Assignments

This repository contains Python programming assignments completed as part of my Data Analytics course at Upcode.

## 📚 Assignments

### 1. `assignment1.py` — Python Fundamentals
Practised basic mathematical operations and problem-solving using Python.

- Finding the square root of a perfect square
- Calculating powers using the exponentiation operator and a `for` loop
- Calculating factorials using recursion

**Concepts:** Functions, loops, conditional statements, return values, and recursion.

### 2. `Assignment-shopping_list.py` — Shopping Cart Application
Developed a menu-driven shopping cart application to manage products and calculate purchase totals.

**Features:**
- Display available products and prices
- Add products to the cart with selected quantities
- View cart items and calculate the grand total
- Remove products from the cart

**Concepts:** Functions, lists, dictionaries, loops, conditional statements, `match-case`, user input, and list operations.

### 3. `prod_sort_by_rating.py` — Product Sorting
Created a program to display product information and sort products by customer rating in descending order.

**Concepts:** Lists, dictionaries, nested data structures, custom functions, sorting, loops, and formatted output.

### 4. `python_class.py` — Employee Management Using OOP
Created an employee management example using object-oriented programming.

**Features:**
- Created an `Employee` parent class
- Created `PermanentEmployee` and `ContractEmployee` child classes
- Reused common employee details through inheritance
- Displayed employee information using class methods

**Concepts:** Classes, objects, constructors, inheritance, `self`, `super()`, and method overriding.
